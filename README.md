# openRigWeb

Marketing/landing website for the openRig project.

Plain HTML + vanilla JavaScript. No build step required — just open `index.html` or serve it with any static file server.

## Development

```bash
# Serve locally (Python)
python3 -m http.server 8080

# Or with npx
npx serve .
```

## Deployment

Drop the contents of this repo onto any static hosting provider (GitHub Pages, Netlify, Cloudflare Pages, etc.).
